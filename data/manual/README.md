# 手动数据说明

免费数据源拿不到的部分（或想用更权威的口径覆盖自动数据），把数字填进下面的 CSV 即可，网页会自动读取并展示：

| 文件 | 用途 | 建议来源 |
| --- | --- | --- |
| `manual_ipo.csv` | 月度 IPO 募资、再融资、解禁、重要股东净减持 | 东方财富数据中心、交易所月度统计 |
| `manual_institutions.csv` | 季度公募仓位、公募/险资/社保/北向持股市值 | 基金季报、金融监管总局、上市公司季报汇总 |
| `manual_northbound.csv` | 北向资金月度净买入（2024年8月后官方停止披露） | 港交所、机构研报 |

规则：
- 第一行必须是表头，列名不要改；
- 没有的月份/季度留空即可，程序会自动忽略空值；
- 保存后刷新网页即可看到。
